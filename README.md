# مساحة — موقع تأسيسي

نسخة أولية لموقع عربي باتجاه RTL، مبنية باستخدام React وVite، مع طبقة بيانات PostgreSQL عبر Supabase.

## ما الموجود الآن؟

- صفحة رئيسية متجاوبة باللغة العربية.
- أقسام تعريفية ومميزات ونموذج تواصل.
- صفحة `/admin` لتسجيل الدخول وإدارة المقالات والرسائل.
- مخطط قاعدة بيانات PostgreSQL وسياسات Row Level Security.
- إعداد نشر متوافق مع Vercel.

> الاسم والنصوص الحالية مؤقتة. سنحدد هوية الموقع ومجاله ومحتواه في المرحلة التالية.

## التشغيل محليًا

1. ثبّت Node.js.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أضف عنوان مشروع Supabase ومفتاحه العام إلى متغيري البيئة.
5. نفّذ `npm run dev`.

## إعداد قاعدة البيانات

1. أنشئ مشروع Supabase.
2. افتح SQL Editor.
3. نفّذ محتوى الملف `supabase/migrations/202611240001_initial_schema.sql`.
4. من إعدادات API في Supabase انسخ Project URL وanon/publishable key إلى:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`

لا تضع `service_role` key في الواجهة الأمامية أو في مستودع GitHub.

## تفعيل حساب الإدارة

1. أنشئ مستخدمًا من Authentication في لوحة Supabase.
2. بعد إنشاء المستخدم، سيُنشأ له سجل في جدول `profiles` بدور `member`.
3. من SQL Editor، عيّن حسابك مديرًا باستخدام بريدك:

```sql
update public.profiles
set role = 'admin'
where id = (
  select id from auth.users
  where email = 'YOUR_EMAIL@example.com'
);
```

4. افتح المسار `/admin` وسجّل الدخول.

## النشر

اربط المستودع بمشروع Vercel، ثم أضف متغيري البيئة السابقين في إعدادات المشروع. أمر البناء هو `npm run build` ومجلد الناتج `dist`.

## ملاحظات أمنية

- سياسات RLS مفعّلة على كل الجداول.
- الزوار يمكنهم قراءة المقالات المنشورة فقط.
- الزوار يمكنهم إرسال رسائل، لكن لا يمكنهم قراءة صندوق الوارد.
- عمليات إدارة المقالات والرسائل تتطلب حسابًا بدور `admin`.
- لا توجد مفاتيح سرية في ملفات المشروع.
