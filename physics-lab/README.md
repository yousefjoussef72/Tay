# معمل الحركة التوافقية

نسخة مدمجة من معمل الحركة التوافقية الأصلي داخل مشروع Tay Space، مع الاحتفاظ بملفات المحاكاة والدروس والقوانين والتدريب كما هي.

المصدر الأصلي: https://github.com/yousefjoussef72/harmonic-motion-lab

## التشغيل والبناء

من جذر مشروع Tay Space:

```bash
npm install
npm run dev
npm run build
```

أمر البناء ينشئ موقع Tay Space أولًا، ثم يبني المعمل كتطبيق فرعي مستقل في `dist/physics-lab` حتى تظل أنماط المعمل ومكتباته معزولة عن المنصة الأساسية.
